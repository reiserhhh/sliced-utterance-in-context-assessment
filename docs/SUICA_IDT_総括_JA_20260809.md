## 3. 理論はどう進化したか — 五つの機構

### 機構1: 接触による死と、より鋭い置換

- **T3(f)(配備ゲージの発行機関免疫)が死んだ** — ゲージは免疫どころか
  共有フレーム内容を「一致」として**増幅**する(1×シフトで+0.0925 =
  F2構成効果全体の3.54倍)。死の跡地に **T9(偽造原理)** が立った:
  フレーム内容は個人水準(発行機関誤差→人物安定な偽カード)でも
  集合水準(共有機会→偽の一致)でも、同一性様統計を偽造する。
- **T8(e)(角度混雑)が死んだ** — 混雑はチャンス水準(AUC 0.500)。
  置換: 疎で均質なギャラリーでは、誤読される者を決めるのは
  **本人の判読性**(ρ、AUC 0.664)。双子問題ではなく山羊問題。
- **T4-simple も T4-床 も死んだ** — 生き残ったのは複合法則(§4)。

どの死も、より特定的な後継を生んだ。反証は損失ではなく精錬だった。

### 機構2: 判別器そのものの進化(「アイデンティティの定義」が三度鍛えられた)

1. v1: Id = 機会再抽出に安定な偏差成分(T6)。
2. **T6′**: 「安定」は分割方式に依存する — 交互分割は遅い状態を再現成分に
   混入させ、連続分割はbに近づく。欠陥ではなく測定チャネル
   (二分割差 = 状態占有率の読取器フリー推定量)。K2aで検証済み
   (12セル中11で予測包含、順序は完全一致)。
3. **T6″**: 素朴な再現性は**偽造可能** — 発行機関誤差×個人固有サンプリングが
   T6を通過する偽カードを作る(実測 +0.055/+0.059、両knob)。
   パッチ: **機会とフレームを同時に再抽出しても残る成分だけがID**。
   更新後、偽造は破壊され正直な雑音ペナルティに反転(−0.062/−0.087)。
4. v2(符号形式): 更新後の期待値はゼロでなく正直なペナルティ —
   「フレーム誤差から利益を得る読取器は偽造中」。

### 機構3: 遡及の力 — 理論が自分の過去を読み直した

一つの未伝播事実(M4-F7: κ=1.0で著者チャネル係数が正確に0)から、
三つの日付付き遡及型替えが導かれた:

- **F2**: 構成効果はどのknobでも**フレーム所有**(著者シェア −0.949/−0.944、
  κ不変で小数3桁一致)。著者内容は干渉。
- **F4**: 「著者軸」は**複製軸** — 著者を全削除しても法則は生き残り、
  むしろ急峻・安価になる(半一致予算 48.9×→19.9×)。
- **F5**: truth対象は混合物(κ=1.0で½著者+½共通)。頭打ち~0.15は
  カードの情報限界ではなく**読取器の変換**に帰属。

### 機構4: 量的結晶化 — 形容詞が数になった

- リンクの測定: **q = 1.83 [1.71, 1.98]**(読取器はカード減衰のほぼ二乗で
  特性を失う)。K2bの「リンク感受性」の謎を遡って解いた。
- 分散課税の発見と確認: K2dの事後推定 **D ≈ −0.722·ΔV_person**
  (R²=0.9935)を登録済み予測に昇格→K2eの新鮮なペアで標本外確認
  (誤差0.0019)。法則の正しい生まれ方。
- 反方向境界: 証明済みの不等式が**空でない** — 全ペアの50.48%で束縛が
  効いている(314万ペアで違反ゼロ)。
- 回転のcos則: 誤差 ≤0.0035。

### 機構5: 予想の定理化と、比喩の正確な閉じ方

- **T10(錨不可能性)**: C-NFI予想を証明。平行移動不変な単独カード汎関数は
  定数 — 情報のある読取は必ず①発行機関推定(価格: +0.097、1/|P|則)、
  ②ギャラリー(価格: 組成依存)、③座標(価格: 基底45.79%)のどれかを消費する。
  **三つの価格は網羅的で、三つとも実測済み。**
- 身分証明書の比喩は文字通り閉じた: 発行機関(P)・管轄(O)・期限(h)のない
  証明書はなく、**読取機にも値札がある**。

### 番外(最深の教訓): 足場系 — K-R1の逆転

「認証済みの脱フレーム修理は特性読取を改善するはず」(私の事前 .45)
→ **全アームでゼロ化**(事前 .10 の枝が的中)。機構: この世界族では
特性にフレーム非依存の表現がなく、読取器は人×フレーム相互作用を
通してしか人を読めない。**紙を漂白すれば、偽造と一緒に透かしも消える。**
対抗操作は診断専用(前処理禁止)。器具役割の型付け:
特性→カード読取器(ゲージの4.5倍)、機会拘束対象→ゲージ。
