# SUICA × 測定系列の三水準 — 橋渡し文書

作成 2026-08-19(プランナー)。オーナーの学会入力(2026-08-19)と、その
演者の主張の典拠論文を受けて:

> 三枝高大・下司忠大 (2025). 個人差研究における個人間関係の解釈の誤り
> ——測定系列の混同に対する警鐘. パーソナリティ研究, 34(2), 119–134.
> https://doi.org/10.2132/personality.34.2.5

同論文の枠組み:測定系列の違いは異なる水準の知見を生む——
(1) 集団を一度測る → **個人間関係**;(2) 多人数を反復測定 →
**平均的個人内関係**;(3) 特定の一人を反復測定 → **その人についての
知見**——そしてこれらの混同が個人差研究の解釈誤りの源である。

**本プログラムの位置**(オーナー指示):我々の研究はこの系譜と対象も
方法も異なる(自然発生の行動痕跡・メタデータ・ラベル無し主体)が、
**この研究群を支援できる形に作り上げる**。支援とは:同じ区別を大規模
行動データの上で実測し、混同の誤差を数にし、水準3の対象に信頼性の
器具を提供すること。置換ではなく補完である。

| (2) 平均的個人内関係 | X1cの**場の規範**(0.093=平均的な人の場所応答)/X2の**presence**(平均経路構造 +0.111) |

## 2. X4(実行中)— 警鐘の定量化

同一の関係(場所のありふれ度×表現量)を三水準すべてで測り、
**Δ_erg = β_個人間 − β_平均個人内** を判定対象として登録済み
(登録 42f0625;エルゴード世界での零読み検査・非エルゴード世界での
導出値回収をゲートに内蔵)。NONERGODIC が立てば、「集団を一度測って
個人内を語る」誤りの**符号と大きさ**が、8,004人×1,460万事件の上で
数になる——論文の主張への最も直接的な実証支援。

## 3. 本プログラムがこの研究群に提供できるもの

1. **規模と期間**:数千人×数年の自然行動系列(反応性なし)。ESM/日誌
   法の小N・短期間・自己報告反応性を補完する。
2. **水準3の信頼性器具**:個人内パラメータ(勾配・自己相関・応答
   プロファイル)の**所有権相関**(分割半+対応置換帰無)と、減衰なし
   の真分散(交差半共分散)。個人内係数の信頼性はESM文献の急所であり、
   我々のゲート付き推定器(零点を実現設計上で検証済み)は輸出可能な
   方法論である。
3. **混同誤差の実測値**:Δ_erg 系の数値(X4以降)。
4. **登録・ゲート規律そのもの**:欠陥登記#55–#88の規約群(実現骨格
   での零点ゲート、境界領域の第一級化、周辺/主効果の命名等)は
   再現可能性方法論としてそのまま共有できる。

## 4. 支援の境界(統治 — 曲げない)

- 我々の変数は**行動メタデータ**(表現量・場所選択・時刻)であり
  心理状態の自己報告ではない。「支援」は構造的類比と方法論の提供で
  あり、心理的構成概念の同定ではない(§5.4:技術的対象に心理命名を
  しない)。
- **水準3の研究支援 ≠ 個人についての主張**。R-G1(個人主張の永久
  禁止)は不変:我々は個人固有パラメータの**分布と信頼性**をコーパス
  水準で測ることで水準3の研究を支援する。特定個人の読み取りは行わない。
- 心理学的収束の主張には外部接続(理論優先5、オーナー所轄)が必要。
  全てEXPLORATORY・コーパス水準。

## 6. システム要件の定式化(オーナー対話、2026-08-19 追記)

オーナーの構想の定式化:**「一回の記録から、三つの測定系列を、同一の
尺度で読み分けられるシステム」**。従来の三水準は三つの異なる収集
デザインに縛られる(だから別々の研究になり、混同が起きる)。本
プログラムの新しさは**水準の選択を収集時から解析時へ移す**こと:
行動痕跡は密(多人数×各人多時点)なので、一つのデータ流が三つの
測定系列を部分デザインとして全て含む。表現候補(オーナーの
「同じテーマの違うデータ」に対し):「同じテーマを、異なる種類の
資料(行動痕跡)で」/「同一資料からの三系列同時読み出し」
(測定系列 → 読み出し系列)。

**技術的な鍵**:質問紙での三水準統一には水準間測定不変性(同じ項目が
個人間でも個人内でも同じ物を測る)が必要で、これは既知の難所(個人内
因子構造 ≠ 個人間因子構造)。本プログラムの尺度は物理単位(語数・
場所シェア・秒)なので、**水準不変性が項目較正でなく単位の同一性で
保証される**。これが「新しい測定法による支援」の核。

**三水準完備性(システム要件)**:ある関係の測定が三水準完備である
とは、単一のデータ流から (L1) 個人間統計、(L2) 平均個人内統計、
(L3) 個人固有パラメータ+信頼性証明書(所有権相関、零点ゲート済み
推定器)を、同一単位・同一推定器族で産出し、水準間対比(Δ_erg)が
登録されていること。

現有資産の完備性監査:ありふれ度×表現量(X4、走行中)= 初の完全
実例;場所×表現量(X1c)= 範疇版で完備;表現量の経路(X2)= 単一
パラメータゆえ L1 は分布のみ(関係ではない);選択×Big5(S線)=
L1 のみ(状態ラベル不在の原理的制約——外部接続後にのみ拡張可能)。

**X5「エルゴード対比の地図」はこの要件の実演として設計する**:
メタデータ上の複数関係を全て三水準完備で測り、「一つのシステムが
一つの資料から全水準を読む」ことをテーマ横断で示す。

## 7. X4の結果 — 警鐘の実測形(2026-08-19 追記)

X4(commit 8ff1f7f)は判定 **NONERGODIC_SIGN_FLIP**:関係「場所の
ありふれ度×表現量」で、

- **個人間**(水準1):β = **+0.069** [+0.049, +0.091] —— ありふれた
  場所に生活の重心がある人ほど、多く書く。
- **平均個人内**(水準2):β = **−0.007** [−0.011, −0.003] —— 同じ
  人がよりありふれた場所へ移ると、少なく書く。
- 水準差 Δ = **+0.076** [+0.056, +0.097](8,004人;エルゴード世界での
  零読み検査合格 —— 器具は非エルゴード性を製造しない)。

**個人間関係から個人内関係を読むと、この関係では大きさ以前に符号を
誤る。** 三枝・下司 (2025) の警鐘の、自然行動データにおける最も強い
実例。想定機構(命名のみ、未検定):個人間は組成(誰がどこに住むか)
が支配し、個人内は場の規範への応答が支配し、両者が逆向き。

**水準3**(個人固有勾配):登録推定器は推定可能性床の欠如で破綻
(欠陥#89–#91として登記)、NULL-first判定は NOT_OWNED で健全。
精度床付きの注記値は **ρ_own = +0.277** [+0.242, +0.310] —— そして
これは X1c の応答プロファイル 0.279、X2 のリズム 0.259 と並ぶ。
**三つの異なる個人内パラメータが ≈0.27 の狭い帯に揃う**(分離
コホート・この期間で)。表現メタデータの水準3信頼性台地の可能性
として命名(主張ではない)。Big5コホートは再び高い(+0.334)。

## 8. X5の結果 — 地図と所有権カタログ(2026-08-19 追記)

**エルゴード対比の地図**(X5、commit 3097a97、判定
ATLAS_HETEROGENEOUS):混同誤差は関係の性質である。

| 関係 | Δ_erg(分離コホート) | 型 |
|---|---|---|
| ありふれ度×表現量 | +0.076 | **符号反転** |
| ありふれ度×score | −0.025 | 個人間のみ負(未解決) |
| ありふれ度×投稿間隔 | **−0.183** | 同符号2.5倍誇張(地図最大) |
| 休止×表現量 | +0.019 | 水準一致(検出力内) |
| 表現量×score | +0.001 | 水準一致 |

**読み**:**組成(Where=誰がどこに住むか)を経由する関係は非
エルゴード、行動どうしの関係は比較的水準一致**。「集団を一度測って
個人内を語る」危険は一様でなく、関係の型で予測できる——警鐘の精密化。

**水準3所有権カタログ**(個人内パラメータはどれほど本人の属性か;
分割半所有権相関、分離コホート/Big5):

| パラメータ級 | 対象 | 所有権 |
|---|---|---|
| 水準(どれだけ) | 滞在率/締まり/漂流(U3) | **0.77 / 0.89 / 0.94** |
| 応答・動態(どう変わるか) | 応答プロファイル(X1c)/リズム(X2)/関係勾配×5(X5) | **0.22–0.42**(Big5側は全て高い:0.24–0.54) |

命名(主張ではない):**「水準は強く所有され、応答は弱く所有される」**。
なお登録した「≈0.27台地」予測は破れた(1/4)——水準3信頼性は媒体の
定数ではなく関係の性質。登録済み予測が一脚で正直に死ぬこと自体が、
本システムが理論に対しても登録規律で動く証拠である。

## 9. X3の結果 — 支援の誠実な完成形(2026-08-21 追記)

X3(stage-E特性結合、commit 3ccbb24)は判定 **EXPRESSION_TRAIT_SILENT**:
認証済み4座標(生水準・場所調整済み水準・リズム・休止勾配;信頼性
0.89/0.90/0.64/0.54で全て入場)はいずれも Big5 と結合しない(実現帯
|r|≈0.022〜0.037 での有界沈黙)——**同一対集合で選択bagチャネルは
r=0.045 で生存したまま**(SR1 の 0.049 三度目の独立再現)。文献の
「饒舌×性格」主張は、この資料・この検定力では支持されない。

**支援プログラムへの誠実な結論**:本システムが三水準研究に提供する
のは、(1) 単一資料からの三系列読み出し、(2) 水準3パラメータの信頼性
器具、(3) 混同誤差の地図——であって、**性格の代理変数ではない**。
表現メタデータ座標は強く著者所有(誰か)でありながら特性沈黙
(どんな人か)——解離族の第6確認として、むしろ測定系列の区別の
重要性そのものを裏書きする。なお Big5 側 FE 予算(著者0.138/場0.046/
交互0.018)は分離側(0.129/0.055/0.019)と近接——主効果もコホート間で
おおむね移送する(観察)。
