# SUICA × 測定系列の三水準 — 橋渡し文書

作成 2026-08-19(プランナー)。オーナーの学会入力(2026-08-19)と、その
演者の主張の典拠論文を受けて:

> 三枝高大・下司忠大 (2025). 個人差研究における個人間関係の解釈の誤り
> ——測定系列の混同に対する警鐘. パーソナリティ研究, 34(2), 119–134.
> https://doi.org/10.2132/personality.34.2.5

同論文の枠組み:測定系列の違いは異なる水準の知見を生む——
(1) 集団を一度測る → **個人間関係**;(2) 多人数を反復測定 →
**平均的個人内関係**;(3) 特定の一人を反復測定 → **その人についての
知見**——そしてこれらの混同が個人差研究の解釈誤りの源である。

**本プログラムの位置**(オーナー指示):我々の研究はこの系譜と対象も
方法も異なる(自然発生の行動痕跡・メタデータ・ラベル無し主体)が、
**この研究群を支援できる形に作り上げる**。支援とは:同じ区別を大規模
行動データの上で実測し、混同の誤差を数にし、水準3の対象に信頼性の
器具を提供すること。置換ではなく補完である。

## 1. 対応表 — 三水準は既に測られている(饒舌量の上で、ラベル無しに)

| 論文の水準 | 本プログラムの実測対応物(2026-08-19時点) |
|---|---|
| (1) 個人間関係 | S線SR1(選択×Big5、r=0.049)/U3の座標×特性(全て沈黙)/X1cの著者周辺share 0.180 |
| (2) 平均的個人内関係 | X1cの**場の規範**(0.093=平均的な人の場所応答)/X2の**presence**(平均経路構造 +0.111) |
| (3) 個人固有の関係 | X1cの**交互作用**(~1.9%、分割半持続 R=0.279)/X2の**ownership**(ρ_own=0.259;Big5コホート0.637)——「個人固有パラメータが実在し、その人の属性として再現するか」を所有権相関で測る |

さらに本プログラムの**解離族**(5回確認:個人間チャネルは生きたまま、
個人内動態座標は特性沈黙)と**「識別≠安定性」の常設法則**(個人間の
識別統計は個人内の安定性主張を許可しない——U2)は、同論文の警鐘の
行動データ版である:**水準は互いに還元されない、を我々は繰り返し
実測した**。

## 2. X4(実行中)— 警鐘の定量化

同一の関係(場所のありふれ度×表現量)を三水準すべてで測り、
**Δ_erg = β_個人間 − β_平均個人内** を判定対象として登録済み
(登録 42f0625;エルゴード世界での零読み検査・非エルゴード世界での
導出値回収をゲートに内蔵)。NONERGODIC が立てば、「集団を一度測って
個人内を語る」誤りの**符号と大きさ**が、8,004人×1,460万事件の上で
数になる——論文の主張への最も直接的な実証支援。

## 3. 本プログラムがこの研究群に提供できるもの

1. **規模と期間**:数千人×数年の自然行動系列(反応性なし)。ESM/日誌
   法の小N・短期間・自己報告反応性を補完する。
2. **水準3の信頼性器具**:個人内パラメータ(勾配・自己相関・応答
   プロファイル)の**所有権相関**(分割半+対応置換帰無)と、減衰なし
   の真分散(交差半共分散)。個人内係数の信頼性はESM文献の急所であり、
   我々のゲート付き推定器(零点を実現設計上で検証済み)は輸出可能な
   方法論である。
3. **混同誤差の実測値**:Δ_erg 系の数値(X4以降)。
4. **登録・ゲート規律そのもの**:欠陥登記#55–#88の規約群(実現骨格
   での零点ゲート、境界領域の第一級化、周辺/主効果の命名等)は
   再現可能性方法論としてそのまま共有できる。

## 4. 支援の境界(統治 — 曲げない)

- 我々の変数は**行動メタデータ**(表現量・場所選択・時刻)であり
  心理状態の自己報告ではない。「支援」は構造的類比と方法論の提供で
  あり、心理的構成概念の同定ではない(§5.4:技術的対象に心理命名を
  しない)。
- **水準3の研究支援 ≠ 個人についての主張**。R-G1(個人主張の永久
  禁止)は不変:我々は個人固有パラメータの**分布と信頼性**をコーパス
  水準で測ることで水準3の研究を支援する。特定個人の読み取りは行わない。
- 心理学的収束の主張には外部接続(理論優先5、オーナー所轄)が必要。
  全てEXPLORATORY・コーパス水準。
