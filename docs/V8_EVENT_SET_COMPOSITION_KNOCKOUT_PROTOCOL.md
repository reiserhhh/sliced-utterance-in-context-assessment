# V8 Event-Set Composition Knockout Protocol

Status: exploratory protocol on already-opened PANDORA and Essays authors.

The permutation-orbit experiment detected common event-set susceptibility
geometry but no observed-order phase. This knockout asks whether the set
geometry comes from natural within-author event composition or merely from
the shared K formula and event marginals.

Within every corpus, D0/D1/D2 split, context, and event-order slot, events are
sorted by text length and divided into local blocks of approximately 16.
Independent non-identity cyclic reallocations are applied in every slot.
Therefore each pseudo world preserves:

- corpus and split;
- context;
- exactly eight event positions per pseudo author;
- every event vector and its corpus/context/position marginal;
- local text-length rank;

while breaking natural within-author event co-occurrence. PANDORA and Essays
are reallocated independently.

The D0 rank-10 matched spectrum is frozen from natural sets. D1/D2
matched-spectrum HS and fidelity are recomputed in 199 pseudo-set worlds and
tested in one maxT family. The D0 gauge, equal-count author alignment, rank,
and matched spectrum replay the permutation-orbit experiment's frozen
`20260813` reference exactly:

\[
\Delta_{set}
=
S(G_P^{real},G_E^{real})
-
E_{\sigma_P,\sigma_E}
S(G_P^{pseudo},G_E^{pseudo}).
\]

A pass attributes the exploratory EPSG overlap to natural event-set
composition under this operator and matching design. It does not establish
why those events co-occur, causal author choice, personality, cognition,
universality, diagnosis, or clinical validity.
